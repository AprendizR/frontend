🚚 Sistema de Gestão de Transportadora – Frontend

Interface web para gerenciamento de operações de uma transportadora, permitindo controlar clientes, motoristas, veículos, notas fiscais e cargas.

A aplicação permite criar cargas vinculando veículo, motorista e notas fiscais, além de acompanhar o status das entregas.

🛠 Tecnologias

React

TypeScript

Tailwind CSS

Axios

Vite

▶️ Como executar
git clone https://github.com/AprendizR/frontend.git
cd frontend
npm install
npm run dev

A aplicação ficará disponível em:

http://localhost:5173

🎯 Objetivo

Projeto desenvolvido para praticar desenvolvimento front-end moderno com React, integração com API REST e simulação de um sistema real de gestão logística.
